# Proposal

## Why

任務目前以每頁 100 筆的平面清單呈現，雖然每次提交已有批次 ID，使用者仍難以辨認不同批次、搜尋特定檔案及快速重試或整理紀錄。原始檔沒有 Finder 定位入口，現有輸出按鈕又只開啟根目錄，使尋找來源與成果需要額外操作。

## What Changes

- 將一次確認提交視為一個批次，呈現批次清單、全部任務入口、狀態數量與可修改的批次名稱；沿用既有批次歸屬。
- 選檔、拖入檔案或加入資料夾後，自動在背景讀取每個媒體檔案的時長，不必先選輸出目錄或手動預覽；匯入清單、批次預覽及提交後任務列表／詳情顯示時長，並區分讀取中、讀取失敗與已知時長。
- 以批次名稱或檔名搜尋，與任務狀態組合篩選；搜尋涵蓋完整選定範圍，在分頁前執行。
- 提供單筆、選取多筆與整批的明確操作範圍，以及獨立的「重試此批失敗任務」入口，保留原批次及重試歷史。
- 新增「移除任務紀錄」，確認時顯示批次／選取範圍、數量、原始檔與成果保留，以及移除後無法從原任務查看或重試。等待中的任務同時撤出佇列；執行或取消中的任務必須先停止。
- 從任務列選單及詳情在 Finder 定位原始檔與成果實際位置，明確呈現尚無成果、路徑遺失或開啟失敗。

## Capabilities

### New Capabilities

- `desktop-task-management`：桌面任務的來源時長讀取與顯示、批次命名與導覽、跨頁搜尋及篩選、選取與操作範圍、只移除紀錄，以及原始檔／成果的 Finder 定位。

### Modified Capabilities

無。主規格尚未包含桌面批次管理能力；本變更新增獨立規格，沿用而不複製或改寫 `add-macos-desktop-batch-transcription` 中的任務生命週期與輸出契約。

## Impact

- Python：重用 `src/asr_desktop/intake.py` 的媒體探測，提供獨立於輸出設定的唯讀時長檢查；`database.py`、`workspace.py` 的批次查詢、名稱保存、共用篩選條件、多筆操作與交易式紀錄移除；檢查與 `scheduler.py` 的執行／回收狀態協作。
- SwiftUI：`desktop/Sources/ASRDesktopApp/DesktopView.swift` 的來源背景檢查、各處時長顯示、批次導覽、搜尋、狀態篩選、多選、確認視窗及 Finder 入口；必要的可測試邏輯置於既有 `ASRDesktopCore`。
- 協定與文件：擴充本機操作與相容欄位，更新 `desktop/PROTOCOL.md`、`desktop/USAGE.md` 與相關測試；維持既有 CLI 呼叫行為。
- 不新增外部服務或套件；不修改推論模型、輸出命名、執行順序、快取清理或檔案刪除功能。本提案不包含實作、Git 操作或發版。
